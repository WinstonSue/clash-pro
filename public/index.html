        使用帮助

        接入 Clash Verge

        复制配置链接，在 Clash Verge 中导入并启用。增删供应商、调整顺序或切换代理方式后刷新订阅。

        供应商分流

        导入临时 HTTPS 订阅，为 Agent 和日常分别排序。两条线路共用地区，按各自的顺序尝试节点。

        地区心跳

        查看可用端点，按需设置检查间隔和额外地区。出现告警时，可从提醒打开对应供应商的导入弹窗。

        Tailscale 跳板

        两台设备加入同一 Tailscale 网络。出口机开启共享并授权，目标机用配对码启用，然后导入或刷新 Clash Verge 配置。

        指定下载（可选）

        在下载工具里手动填写本机 HTTP 代理。供应商直连模式下，境外下载走日常线路，国内和内网优先直连。
